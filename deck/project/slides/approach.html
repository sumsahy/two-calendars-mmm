Fixed rule

Holds if P(shift helps) ≥ 0.80

The rule and the scenarios were committed to git before any model ran. The main world is a deliberate close call: a data error can only flip a decision that sits near the boundary. Six more worlds and extra random seeds test the rest.

Oracle uses the true daily TV delivery: not available in real life, it separates calendar error from model error.
