So it never happens again

A refresh gate that an LLM can only make stricter

1

Schema

The LLM reads each vendor spec and answers in fixed fields only: grain, calendar, week start, date label.

2

Grounding

Every claim must quote the spec word for word. A quote not found in the spec is thrown out.

3

Data cross-check

Claims must match the file itself: spacing of dates, which weekday they fall on, first-of-month keys.

4

Contract

Anything unknown blocks the refresh. Weekly data must be split by day, and the split must conserve spend to the cent.

Proven by tests

  • A made-up quote is discarded
  • An LLM that obeys an instruction hidden in a spec is overruled by the data
  • A vendor silently switching to week-ending dates is blocked
  • An unregistered file is never joined

12 tricky specs, 0 misaligned ones passed. The LLM reads what the data can’t say; the data checks what the LLM can’t be trusted to say.

Why an LLM at all: a Sunday date could mean week starting or week ending, and a first-of-month date could be a fiscal month. Only the spec says which. The eval labels and the recorded readings were both written by Claude, so the score is not independent; a live Groq run is the independent check.
